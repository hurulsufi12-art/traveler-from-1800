# One Sentence for a Traveler from 1800

One sentence (179 characters, limit 200): the modern internet explained to someone arriving from 1800, built only from things they already know — libraries, letters, wires — with no word coined after their time.

> Imagine every library on earth shelved in one room, every letter delivered in a blink, and any stranger's voice reachable through a wire — all of it sitting in a box on your desk.

`main.py` (Python 3.13, stdlib only) writes that sentence to `/output/entry.txt`. Deterministic: the same text on every run.
